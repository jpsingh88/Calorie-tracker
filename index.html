☁️ Laptop ↔ iPhone Cloud Sync (Firebase Realtime DB)
To sync data between your iPhone and Laptop:
1. Go to console.firebase.google.com → Create Project → Build → Realtime Database → Create Database (Start in Test Mode).
2. Copy your Database URL (e.g., https://my-tracker-default-rtdb.firebaseio.com) and paste it below on both your Laptop and iPhone with the same Sync ID.
Every meal/workout change auto-syncs when Firebase URL is configured.
